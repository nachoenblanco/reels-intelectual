# Reels intelectual

Sistema de feed interactivo para la reactivación, consumo y cribado de recursos científicos, técnicos, artísticos y humanísticos.

Diseñado para uso directo en dispositivos móviles vía **GitHub Pages** con interfaz táctil tipo historias/reels.

## Características
- **Cero desvío lateral**: bloqueo estricto del eje horizontal para evitar desplazamientos accidentales al interactuar con el pulgar.
- **Acciones directas**:
  - `Leído`: registra el contenido como consumido en la sesión.
  - `Cuarentena`: envía recursos en desuso (ropa vieja) al almacén frío sin eliminarlos definitivamente.
  - `Investigar`: prioriza el contenido para su incorporación en Zotero u Obsidian.
  - `Pasar`: avanza a la siguiente tarjeta manteniendo el enlace en rotación.
- **Previsualizaciones automáticas**: miniaturas de YouTube con reproducción visual, tarjetas OpenGraph de GitHub y carátulas académicas para preprints y artículos científicos.
- **Filtros temáticos**: Laboratorio, Atelier, Café sesudo, Herramientas y Docencia.
- **Persistencia autónoma**: el estado de lectura y cuarentena se conserva localmente en el navegador móvil sin necesidad de servidor activo ni conexión local.
